UbunX é uma distribuição Linux personalizada baseada no ecossistema robusto e estável do Zorin OS, projetada para oferecer uma experiência de desktop moderna, intuitiva e altamente compatível com usuários que migram do Windows ou macOS.

Principais Características do UbunX
Base Ubuntu LTS: Construída sobre a confiabilidade do Ubuntu (atualmente Ubuntu 24.04 LTS no Zorin 18), garantindo suporte oficial até 2029 e acesso a um vasto repositório de software. 
Interface Familiar: Utiliza o ambiente de desktop GNOME 3 personalizado com o tema Zorin Desktop, permitindo que o usuário altere visualmente o sistema para imitar o Windows 10/11, macOS ou uma estética Linux única através do Zorin Appearance. 
Compatibilidade Windows: Integra nativamente o Wine e ferramentas de conversão, permitindo a execução direta de aplicativos e jogos do Windows sem necessidade de virtualização complexa.
Otimização e Desempenho: Inclui a versão Lite (baseada em Xfce) para hardware antigo ou limitado, e a versão Core/Pro (GNOME) para máquinas modernas, oferecendo drivers atualizados (como NVIDIA 570+ no Zorin 17.3/18) e kernel Linux 6.14+.
Ecosistema de Aplicações: Vem pré-carregado com essencial como LibreOffice, Firefox (ou Brave), GIMP e VLC, além de acesso fácil ao Ubuntu Software Center e suporte a Flatpak/Snap.
Público-Alvo
O UbunX é ideal para iniciantes em Linux, usuários corporativos que precisam de estabilidade e compatibilidade, e entusiastas que desejam substituir o Windows sem perder a familiaridade com a interface gráfica e as ferramentas do dia a dia.
